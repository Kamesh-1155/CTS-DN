# Week 7 - Git HOL 5

## Objective
Practice synchronizing the local repository with the remote repository using Git pull and Git push.

## Commands Executed

```bash
git status
git branch
git remote -v
git pull origin main
git add Week7/HOL5/GIT_HOL5.md
git commit -m "Week 7 HOL 5 - Repository synchronization"
git push origin main
```

## Outcome

- Verified repository status.
- Pulled the latest changes from the remote repository.
- Committed a documentation update.
- Successfully pushed the latest changes to GitHub.
